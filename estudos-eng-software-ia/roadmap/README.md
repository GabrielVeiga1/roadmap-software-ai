# Roadmap

Lista de temas por fase, sem prazo fixo. Cada item é um assunto; o material eu pesquiso por conta própria (YouTube, docs oficiais, fóruns), sempre com recursos gratuitos. Só marco uma caixinha quando consigo explicar o tema sem consultar.

- [Fase 0: Fundamentos](fase-0-fundamentos.md): terminal, Git, redes, sistema operacional
- [Fase 1: Engenharia de software](fase-1-engenharia-de-software.md): Python, algoritmos, design, testes, APIs, SQL, Docker, CI
- [Fase 2: Sistemas distribuídos](fase-2-sistemas-distribuidos.md): escala, filas, resiliência, arquitetura
- [Fase 3: Observabilidade](fase-3-observabilidade.md): logs, métricas, traces, OpenTelemetry, Grafana
- [Fase 4: ML e LLMs](fase-4-ml-e-llms.md): matemática mínima, redes neurais, Transformers
- [Fase 5: Engenharia de IA](fase-5-engenharia-de-ia.md): RAG, agentes, MCP, evals, observabilidade de LLM

Visão em diagrama: [fluxograma](fluxograma.md).

Se o objetivo do momento é observabilidade com modelo local, dá para adiantar a Fase 3 logo depois da Fase 1.
